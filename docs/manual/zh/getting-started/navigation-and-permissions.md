# 导航与权限

![已登录应用框架：1 语言，2 通知铃铛，3 头像，4 侧边栏](/images/navigation/navigation.png){.manual-shot}

| 编号 | 控件 | 前置、操作、结果、权限 |
|---|---|---|
| 1 | 语言 | 点击切换显示语言；资料更新失败时保留原语言。 |
| 2 | 通知铃铛和未读数 | 仅通知权限角色可见；点击打开通知页并显示未读数。 |
| 3 | 头像 | 点击打开当前登录账号的设置页。 |
| 4 | 侧边栏 | 只显示账号有权使用的模块；输入其他页面地址不能获得权限，没有权限时返回可访问页面。 |

分页和每页数量仅适用于展示这些控件的页面；它们只改变当前结果页，不改变权限。
