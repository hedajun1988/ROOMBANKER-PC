# 找回密码

![找回密码：1 注册邮箱，2 图形码，3 刷新安全图片，4 邮件验证码，5 发送验证码，6 新密码，7 按住显示，8 重置密码，9 返回登录](/images/auth/recovery.png){.manual-shot}

关键区域放大：

![找回密码表单控件](/images/zoom/password-recovery-form-controls.png){.manual-shot}

| 编号 | 控件 | 前置、操作、结果、失败或风险 |
|---|---|---|
| 1 | Registered Email（注册邮箱） | 输入已注册邮箱。 |
| 2 | 图形码 | 输入显示的图形码；验证成功的图形码只能使用一次。 |
| 3 | 刷新安全图片 | 点击图片换取新的图形码。 |
| 4 | 邮件验证码 | 输入发送到注册邮箱的验证码。 |
| 5 | Send Code（发送验证码） | 图形码验证后发送邮件码，并等待 60 秒后才能再次发送；再次可用后可申请新码，页面不显示验证码到期时间。 |
| 6 | New Password（新密码） | 输入合规的新密码。 |
| 7 | 按住显示密码 | 按住眼睛控件时才显示新密码，松开即隐藏。 |
| 8 | Reset Password（重置密码） | 提交有效字段。成功会更新真实密码并清除平台账号锁定；校验被拒绝时表单仍可修改。 |
| 9 | Back to Login（返回登录） | 不重置密码并返回登录。 |
