# 注册

![注册：1 邮箱，2 验证码，3 发送验证码，4 密码，5 按住显示密码，6 确认密码，7 按住显示确认密码，8 注册，9 返回登录](/images/auth/register.png){.manual-shot}

| 编号 | 控件 | 前置、操作、结果、失败或权限 |
|---|---|---|
| 1 | 邮箱 | 输入允许注册的邮箱地址；以 `@dusun.com` 结尾的平台账号不能自行注册。 |
| 2 | 验证码 | 输入发往该邮箱的邮件验证码。 |
| 3 | Send Code（发送验证码） | 输入有效后发送邮件码；发送后重发控件禁用 60 秒。 |
| 4 | 密码 | 输入至少 8 个字符的密码；无效输入不能注册。 |
| 5 | 按住显示密码 | 按住眼睛控件时才显示密码，松开即隐藏。 |
| 6 | 确认密码 | 与密码完全一致地再次输入；不一致时不能注册。 |
| 7 | 按住显示确认密码 | 按住眼睛控件时才显示确认密码，松开即隐藏。 |
| 8 | Register（注册） | 全部校验通过后创建允许自注册的普通用户账号。 |
| 9 | Back to Login（返回登录） | 不创建账号并返回。 |

@dusun.com 平台账号不可自注册；公司员工须由公司管理员添加。
