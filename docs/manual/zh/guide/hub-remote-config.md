# 远程配置

从选定 Hub 打开 **Remote Config**。可用控件取决于当前登录角色和 Hub 状态。发送邀请、修改 PIN、转移角色、启用 SSH 或重启 Hub 前，请核对目标和确认提示。

![用户管理与 App User 卡片：1 用户管理，2 角色，3 房间范围，4 邮箱，5 发送邀请，6 App User，7 配置](/images/hubs/hub-remote-config-main.png){.manual-shot}

| 编号 | 控件 | 前置和操作 | 结果、禁用、权限或风险 |
|---|---|---|---|
| 1 | User Management（用户管理） | 选择折叠标题，显示或隐藏邀请和 App User 区域。 | 折叠不会修改 Hub 设置。 |
| 2 | 邀请角色 | 创建邀请前选择 **Admin** 或 **Normal User**。 | 无权使用的角色会被禁用；Admin 邀请使用全部房间。 |
| 3 | 房间范围 | 为 Normal User 选择全部房间或允许的房间。 | 部分范围未选房间时不能发送。 |
| 4 | 邮箱 | 输入收件人邮箱。 | 空值或格式无效不能发送邀请。 |
| 5 | Send Invitation（发送邀请） | 核对角色、房间范围和邮箱后提交。 | 这是高风险操作；成功时发送邀请，被拒绝或失败时用户列表不变。 |
| 6 | App User | 展开或折叠已有远程 App User 卡片。 | 仅显示或导航。 |
| 7 | 配置 | 打开目标 App User 卡片。 | 用户或当前操作者不可配置时按钮不可用。 |

![邀请用户表单：1 角色，2 房间范围，3 邮箱，4 发送邀请](/images/hubs/hub-remote-config-invite.png){.manual-shot}

| 编号 | 控件 | 前置和操作 | 结果、禁用、权限或风险 |
|---|---|---|---|
| 1 | 角色 | 选择当前操作者有权邀请的角色。 | 选择 Admin 会将范围重置为全部房间。 |
| 2 | 房间范围 | 对 Normal User 选择全部房间或允许的子集。 | 部分范围至少需要一个房间。 |
| 3 | 邮箱 | 输入收件人邮箱。 | 必填。发送失败时，请检查邮箱、角色和房间后再重试。 |
| 4 | Send Invitation（发送邀请） | 复核全部字段后提交。 | 成功时发送邀请；报错或禁用时不会发送。 |

![App User 设置：1 通知方式，2 电话，3 删除电话，4 添加电话，5 配置 PIN，6 转移目标，7 转移超级管理员，8 保存](/images/hubs/hub-app-user-settings.png){.manual-shot}

| 编号 | 控件 | 前置和操作 | 结果、禁用、权限或风险 |
|---|---|---|---|
| 1 | 通知方式 | 为告警、故障、事件和操作选择送达方式。 | 必须主保存；失败时已确认远程配置不变。 |
| 2 | 电话号码 | 为显示的 App User 输入格式正确的号码。 | SMS 或电话呼叫可能要求号码；号码无效不能保存。 |
| 3 | 删除电话 | 仅 Super Admin 且电话超过一条时可见。 | 删除尚未保存的该行；仍需主保存。 |
| 4 | 添加电话 | Super Admin 少于三条电话时可见。 | 新增未保存行；普通 App User 最多一条电话且没有此控件。 |
| 5 | Configure PIN（配置 PIN） | 为具有有效设备用户编号前缀的 App User 打开 PIN 草稿。 | 草稿后仍须保存主设置。 |
| 6 | 转移目标 | 当前 Super Admin 选择符合条件的非本地 App User。 | 仅选择不会转移角色。 |
| 7 | Transfer Super Admin（转移超级管理员） | 核对目标并打开确认。 | 高风险，仅获授权的当前 Super Admin 可继续。 |
| 8 | 保存 | 保存变更的方式、电话和暂存 PIN。 | 忙碌、不可用、无效或未变更的表单不会产生远程更新。 |

![App User PIN 对话框：1 固定前缀，2 可编辑数字，3 取消，4 保存](/images/hubs/hub-app-user-pin.png){.manual-shot}

| 编号 | PIN 控件 | 前置和操作 | 结果或失败 |
|---|---|---|---|
| 1 | 固定前缀 | 查看由设备用户编号派生的两位数字。 | 只读。 |
| 2 | PIN 数字 | 输入四位数字后缀。 | 非数字或未完整输入不能形成有效草稿。 |
| 3 | 取消 | 关闭草稿对话框。 | 丢弃未保存编辑。 |
| 4 | 保存 | 保存有效草稿，再使用主设置保存。 | 仅保存草稿不会修改 PIN，主设置保存成功后才会修改。 |

![超级管理员转移确认：1 后果，2 取消，3 确认](/images/hubs/hub-super-admin-transfer-confirm.png){.manual-shot}

| 编号 | 确认控件 | 操作 | 结果、失败或高风险后果 |
|---|---|---|---|
| 1 | 后果 | 再次核对来源和目标。 | 确认会交换角色、设备用户编号和房间范围；清除 PIN；移动通知选择；并清除 PC 第二、第三电话号码。 |
| 2 | 取消 | 关闭确认。 | 不发送转移请求。 |
| 3 | 确认 | 发送已授权的转移。 | 只有显示成功提示且用户列表显示新角色才算转移完成。出错时先检查列表；角色已变更时不要重复转移。 |

![维护：1 维护区域，2 SSH 开关，3 重启 Hub](/images/hubs/hub-maintenance.png){.manual-shot}

| 编号 | 控件 | 前置和操作 | 结果、禁用、权限或风险 |
|---|---|---|---|
| 1 | Maintenance（维护） | 展开或折叠维护控件。 | 仅显示，不发送远程命令。 |
| 2 | SSH 开关 | 授权操作者核对目标 Hub 后才启用或停用。 | SSH 是安全远程维护通道。开关恢复原状或没有成功提示时，不能认为远程设置已改变，也不要连续重试。 |
| 3 | Restart Hub（重启 Hub） | 核对运维窗口后打开确认。 | 确认后等待 Hub 状态和监控结果。失败或没有成功提示不能视为已重启。 |

![重启 Hub 确认：1 警告，2 取消，3 确认](/images/hubs/hub-restart-confirm.png){.manual-shot}

| 编号 | 确认控件 | 操作 | 结果、失败或风险 |
|---|---|---|---|
| 1 | 警告 | 核对 Hub 名称和 SN。 | 显示离线 30-60 秒仅为估算，请以 Hub 状态和监控判断重启是否完成。 |
| 2 | 取消 | 关闭对话框。 | 不发送重启。 |
| 3 | 确认 | 发送已授权重启。 | 等待 Hub 状态和监控结果，不能因对话框关闭就判断成功。 |
