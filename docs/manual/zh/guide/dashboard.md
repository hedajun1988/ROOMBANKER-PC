# 仪表盘

![仪表盘：1 KPI 卡片，2 角色标签，3 最近事件，4 查看全部](/images/dashboard/dashboard.png){.manual-shot}

| 编号 | 控件 | 前置、操作、结果、权限 |
|---|---|---|
| 1 | KPI 卡片 | 卡片显示当前权限范围内的公司、Hub 和报警汇总。点击可用卡片进入相应且有权限的列表。 |
| 2 | 角色标签 | 标识当前账号角色，仅作信息展示，不会改变访问范围。 |
| 3 | Recent Events（最近事件） | 显示最近操作活动；加载中请等待面板，空结果会显示空状态。 |
| 4 | View All（查看全部） | 打开通知页；目标页仍受通知权限限制。 |

Dashboard 数值按当前账号权限显示。加载中或出错不代表系统没有风险。
