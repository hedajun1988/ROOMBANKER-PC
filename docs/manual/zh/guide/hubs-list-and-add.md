# Hub 与注册

![Hub 列表操作：1 状态，2 模式，3 公司，4 SN，5 添加 Hub，6 设备数，7 布撤防，8 详情，9 指派，10 删除](/images/hubs/hub-list-actions.png){.manual-shot}

| 编号 | 控件 | 用途和结果 |
|---|---|---|
| 1 | 状态筛选 | 按 Hub 状态缩小列表。 |
| 2 | 模式筛选 | 按当前布撤防模式缩小列表。 |
| 3 | 公司筛选 | 仅显示选定公司的 Hub。 |
| 4 | SN 搜索 | 按 Hub 序列号筛选。 |
| 5 | 添加 Hub | 打开注册向导。 |
| 6 | 设备数 | 打开该 Hub 的子设备。 |
| 7 | 布防或撤防 | 直接变更选定 Hub 的模式。操作前核对 Hub 和目标模式；失败时不能认为模式已改变。 |
| 8 | 详情 | 打开选定 Hub 详情。 |
| 9 | 指派 | 打开指派，不立即变更。 |
| 10 | 删除 | 打开删除确认。 |

![指派 Hub：1 公司，2 人员，3 取消，4 保存](/images/hubs/hub-assign-modal.png){.manual-shot}

| 编号 | 控件 | 用途和结果 |
|---|---|---|
| 1 | 公司 | 选择目标公司。 |
| 2 | 指派给人员 | 选定公司后搜索或选择符合条件的人员。 |
| 3 | 取消 | 关闭且不改变指派。 |
| 4 | 保存 | 获得授权后保存指派；失败时当前指派保持不变。 |

![删除 Hub 确认：1 后果，2 取消，3 确认](/images/hubs/hub-delete-confirm.png){.manual-shot}

| 编号 | 控件 | 用途和风险 |
|---|---|---|
| 1 | 解绑后果 | 核对 Hub：删除会解除个人/公司绑定，但物理 SN 记录保留。 |
| 2 | 取消 | 关闭且不删除。 |
| 3 | 确认 | 授权删除后，在重新绑定前 PC 不可见。 |

![添加 Hub 第 1 步：1 通电并连接，2 准备完成继续，3 关闭](/images/hubs/hub-add-step-1.png){.manual-shot}

| 编号 | 第 1 步控件 | 前置、操作、结果、失败或权限 |
|---|---|---|
| 1 | Power & Connect（通电并连接） | 继续前为 Hub 供电，并建立所需的以太网或 LTE 连接。 |
| 2 | Ready - Continue（准备完成继续） | 进入 SN 输入；不会添加或绑定 Hub。 |
| 3 | Close（关闭） | 退出向导，不会添加 Hub。 |

![添加 Hub 第 2 步：1 Hub SN，2 返回，3 下一步，4 关闭](/images/hubs/hub-add-step-2.png){.manual-shot}

| 编号 | 第 2 步控件 | 前置、操作、结果、失败或权限 |
|---|---|---|
| 1 | Hub SN | 输入设备标签上的 SN（序列号），仅允许字母和数字；空值或格式无效时不能继续。 |
| 2 | Back（返回） | 返回通电并连接步骤，同时保留向导，不会绑定 Hub。 |
| 3 | Next（下一步） | 校验 SN 后打开公司归属选择。 |
| 4 | Close（关闭） | 取消向导，不创建绑定。 |

![添加 Hub 第 3 步：1 搜索，2 不选择公司，3 公司选项，4 加载更多，5 确认添加 Hub](/images/hubs/hub-add-step-3.png){.manual-shot}

| 编号 | 第 3 步控件 | 前置、操作、结果、失败或权限 |
|---|---|---|
| 1 | 公司搜索 | 为已校验的 SN 搜索可选择公司。 |
| 2 | No Company（不选择公司） | 清除选择。清除后页面隐藏 Confirm Add Hub，因此不能绑定。 |
| 3 | 公司选项 | 选择目标公司；继续前核对归属。 |
| 4 | Load more（加载更多） | 加载下一页公司。公司搜索请求失败时，下拉框会显示 Retry；重试保留向导且不会绑定 Hub。 |
| 5 | Confirm Add Hub（确认添加 Hub） | 选择公司后可见。它是高影响绑定操作；成功后 Hub 绑定到所选公司，校验错误或失败时向导保留，可修正或重试。 |

**删除风险。** 删除 Hub 只解除个人和公司绑定；重新绑定前 PC 不可见。物理 SN 记录会保留，不会被物理删除。
