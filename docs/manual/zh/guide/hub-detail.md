# Hub 详情

![Hub 详情：1 详情页签，2 Remote Config，3 子设备，4 编辑，5 撤防，6 自定义模式](/images/hubs/hub-detail-main.png){.manual-shot}

| 编号 | 控件 | 前置、操作、结果、失败或权限 |
|---|---|---|
| 1 | Hub 详情 | 显示选定 Hub 的名称、SN、归属、状态和当前可用控件。 |
| 2 | Remote Config | 打开选定 Hub 的配置。用户、SSH 和重启控件受角色限制，另见对应章节。 |
| 3 | 子设备 | 打开选定 Hub 的子设备列表；不会物理删除任何设备。 |
| 4 | 编辑 | 授权用户修改 Hub 名称或公司归属。请求被拒绝时原归属不变。 |
| 5 | 撤防 | 打开该 Hub 的布撤防确认；提交前核对目标和当前安防上下文。 |
| 6 | 自定义模式 | 仅在已配置且启用时选择自定义模式。加载中或禁用控件不能作为状态变更反复提交。 |

![Hub 日志：1 下载，2 删除，3 获取日志，4 导出消息到 Excel](/images/hubs/hub-detail-logs.png){.manual-shot}

| 编号 | 日志或导出控件 | 前置、操作、结果、失败或权限 |
|---|---|---|
| 1 | 下载 | 下载选定的可用日志。缺少下载信息或授权失败时会报告错误，不改变 Hub 归属。 |
| 2 | 删除 | 为选定日志打开删除确认；确认前不会删除。 |
| 3 | Get Log（获取日志） | 从 Hub 收集日志，成功后刷新列表；失败时原列表不变。 |
| 4 | Export Messages to Excel（导出消息到 Excel） | Export 卡片为该 Hub 消息发送导出请求。失败不会改变 Hub 或日志记录。 |

![删除 Hub 日志确认：1 警告，2 取消，3 OK](/images/hubs/hub-log-delete-confirm.png){.manual-shot}

| 编号 | 确认控件 | 用途和风险 |
|---|---|---|
| 1 | 警告 | 继续前确认显示的日志就是目标日志。 |
| 2 | 取消 | 关闭对话框，不删除日志。 |
| 3 | OK | 授权请求成功后只删除选定日志；不会解除 Hub 绑定、物理删除 SN 或删除子设备。 |
