# PC 操作日志

![PC 操作日志：1 类型，2 关键词，3 日期范围](/images/pages/operation-logs.png){.manual-shot}

| 编号 | 控件 | 前置、操作、结果、权限 |
|---|---|---|
| 1 | 类型 | 选择操作类型以缩小日志。 |
| 2 | 关键词 | 输入操作内容或操作者名称中的文字，以缩小记录范围。 |
| 3 | 日期范围 | 选择可选的 From（开始）和 To（结束）日期，仅显示该时段内的记录。 |

展示分页时仅用于切换较早记录；页面没有导出入口。

<div class="manual-note">截图使用虚构资料。截取或分享自己的页面时，请遮盖登录信息、Hub 序列号、远程访问信息、电话号码和个人资料。</div>
