# 故障排查

## 登录与验证码

检查注册邮箱和密码，再使用当前图形码重试。需要时刷新图形码；验证后只能使用一次。60 秒后可申请新的邮件码。页面不显示验证码到期时间或账号锁定前剩余尝试次数。

## 菜单或操作缺失

确认当前登录账号和角色后刷新页面。没有权限的模块和操作会隐藏；输入其他页面地址不能获得权限，无权限时会返回可访问页面。请平台超级管理员检查权限分配。

## 列表、筛选与时间

清除或缩小筛选条件，核对日期顺序和 Hub SN；存在分页时切换页码。时间按当前电脑本地时区显示。

## Hub 离线与远程操作

管理前检查 Hub 在线状态。SSH 或重启后核对 Hub 状态和监控结果。不要推测重启时长，也不要盲目重试失败的高风险操作。

## 浏览器与文档

刷新页面，从首页重新选择语言，或在受支持浏览器中重试。说明书仍无法打开时请联系管理员。
