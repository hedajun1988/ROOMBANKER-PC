# 操作安全

每次高权限操作前确认目标、当前角色、业务影响和恢复路径。

| 操作 | 前置和后果 | 失败和回退 |
|---|---|---|
| 删除 Hub | 授权用户确认目标。操作解除个人和公司绑定；重新绑定前 PC 不可见。物理 SN 记录保留。 | 请求失败不能视为已解绑；需要恢复访问时重新绑定目标 Hub。 |
| SSH | 授权用户确认 Hub。SSH 是安全远程维护通道。 | 开关恢复原状或没有成功提示时，不能认为设置已改变，也不要连续重试；使用运维回退流程。 |
| 重启 | 授权用户确认 Hub 和合适的运维窗口。 | 没有成功提示不代表已重启；再次操作前等待 Hub 状态和监控结果。 |
| Super Admin 转移 | 核对两名用户和房间范围。转移交换角色、编号和房间范围；清除 PIN；移动通知选择；清除 PC 第二、第三电话号码。 | 查看转移后账号；转移错误时通过授权管理修正范围。 |
| 删除我的账号 | 确认当前登录身份。操作只删除当前账号。 | 失败时账号不变；不会删除设备或配置。 |
| 删除公司 | 授权用户确认公司。删除后该公司不再出现在可用公司列表中，相关管理操作也无法继续。 | 失败时公司保留；意外状态通过授权管理修正。 |
