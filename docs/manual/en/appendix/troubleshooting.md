# Troubleshooting

## Login and codes

Check the registered email and password, then retry with the current image code. Refresh the image code when needed; it is single-use after verification. After 60 seconds, you can request a new email code. The page does not show when a verification code expires or how many tries remain before an account is locked.

## Missing menus or actions

Confirm the signed-in account and role, then sign in again. Ungranted modules and actions are hidden; ask a platform super administrator to review permission assignments.

## Lists, filters, and time

Clear or narrow filters, confirm date order and Hub SN, then change page if pagination is present. Times are shown in the current computer's local time zone.

## Offline Hub and remote operations

Check Hub online status before management. For SSH or Restart, confirm Hub status and monitoring results. Do not guess restart duration or retry a failed high-risk action blindly.

## Browser and documentation

Refresh the page, select the language again from the home page, or try a supported browser. If the manual still does not open, contact an administrator.
