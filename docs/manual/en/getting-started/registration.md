# Registration

![Registration: 1 Email, 2 verification code, 3 Send Code, 4 password, 5 reveal, 6 confirmation, 7 reveal confirmation, 8 Register, 9 Back to Login](/images/auth/register.png){.manual-shot}

Key area enlarged:

![Registration form controls](/images/zoom/registration-form-controls.png){.manual-shot}

| No. | Control | Prerequisite, action, result, failure or permission |
|---|---|---|
| 1 | Email | Enter an eligible email address. Platform accounts ending in `@dusun.com` cannot self-register. |
| 2 | Verification code | Enter the email verification code received for the address. |
| 3 | Send Code | Sends the email code after valid input. The resend control is disabled for 60 seconds. |
| 4 | Password | Enter a password of at least 8 characters. Invalid input prevents registration. |
| 5 | Hold to reveal password | Hold the eye control to view the password only while pressed. |
| 6 | Confirm Password | Repeat the password exactly; a mismatch blocks registration. |
| 7 | Hold to reveal confirmation | Hold the eye control to view the confirmation only while pressed. |
| 8 | Register | After all validation, creates an eligible normal user account. |
| 9 | Back to Login | Returns without creating an account. |

Platform accounts ending in @dusun.com cannot self-register. Company employees are added by a company administrator.
