# Navigation and permissions

![Authenticated application shell: 1 language, 2 notification bell, 3 avatar, 4 sidebar](/images/navigation/navigation.png){.manual-shot}

| No. | Control | Prerequisite, action, result, permission |
|---|---|---|
| 1 | Language | Select it to switch the display language. A failed profile update keeps the previous language. |
| 2 | Notification bell and unread count | Visible only when the role can access notifications; selects the Notifications page and shows its unread count. |
| 3 | Avatar | Select it to open Settings for the signed-in account. |
| 4 | Sidebar | Shows only pages you can use. Typing another page address does not give access; if you do not have access, ROOMBANKER-PC returns you to a page you can use. |

Pagination and page-size selectors apply only on pages that display them; they change the visible result page, not permissions.
