# Password recovery

![Password recovery: 1 registered email, 2 image code, 3 refresh image, 4 email code, 5 Send Code, 6 new password, 7 reveal, 8 Reset Password, 9 Back to Login](/images/auth/recovery.png){.manual-shot}

| No. | Control | Prerequisite, action, result, failure or risk |
|---|---|---|
| 1 | Registered Email | Enter the registered address. |
| 2 | Image code | Enter the displayed image code; a successfully verified image code is single-use. |
| 3 | Refresh security image | Select the image to replace it with a new image code. |
| 4 | Email verification code | Enter the code sent to the registered email. |
| 5 | Send Code | Available after image verification; sends the email code and starts a 60-second wait before sending again. When it becomes available again, you can request a new code. The page does not show when a code expires. |
| 6 | New Password | Enter a compliant replacement password. |
| 7 | Hold to reveal password | Hold the eye control to view the new password only while pressed. |
| 8 | Reset Password | Submit valid values. Success updates the real password and clears a platform-account lock; rejected validation leaves the form available. |
| 9 | Back to Login | Returns to Login without resetting the password. |

<div class="manual-note">Screenshots use fictional data. If you capture or share your own screen, hide sign-in details, Hub serial numbers, remote-access details, phone numbers, and personal information.</div>
