# Deactivated accounts

![Deactivated accounts: 1 company filter, 2 keyword](/images/pages/deactivated-accounts.png){.manual-shot}

| No. | Control | Prerequisite, action, result, permission |
|---|---|---|
| 1 | Company filter | Select a company to limit deactivated records. |
| 2 | Keyword | Enter a keyword to find matching entries. |

The returned list is read-only: there is no restore or edit action. Pagination, where shown, only opens older records.
