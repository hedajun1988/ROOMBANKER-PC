# Dashboard

![Dashboard: 1 KPI cards, 2 role label, 3 Recent Events, 4 View All](/images/dashboard/dashboard.png){.manual-shot}

| No. | Control | Prerequisite, action, result, permission |
|---|---|---|
| 1 | KPI cards | The cards show company, Hub and alarm totals for the permitted account. Select an available card to open its related permitted list. |
| 2 | Role label | Identifies the current account role; it is informational and does not change access. |
| 3 | Recent Events | Shows recent operation activity. While loading, wait for the panel; an empty result displays the empty state. |
| 4 | View All | Opens Notifications. The destination remains subject to notification permission. |

Dashboard values are shown according to the current account's permissions. A loading state or error does not mean there is no risk.
