# PC operation log

![PC operation log: 1 type, 2 keyword, 3 date range](/images/pages/operation-logs.png){.manual-shot}

| No. | Control | Prerequisite, action, result, permission |
|---|---|---|
| 1 | Type | Select an operation type to limit logs. |
| 2 | Keyword | Enter text from the operation content or operator name to narrow the records. |
| 3 | Date range | Select optional From and To dates to show records within that period. |

Pagination, where shown, changes the result page for older records. The page has no export entry.

<div class="manual-note">Screenshots use fictional data. If you capture or share your own screen, hide sign-in details, Hub serial numbers, remote-access details, phone numbers, and personal information.</div>
